# 동해시 재난상황 보고서 자동 생성기

상황전파 메시지를 붙여넣으면 **별지 제1호서식** 재난상황 보고서를 자동으로 만들어 주는 도구입니다. 초기 대응용으로 설계되었으며, 완전히 **오프라인**으로 동작합니다(인터넷 불필요).

## 사용법

1. `index.html`을 더블클릭하면 브라우저에서 열립니다.
2. 왼쪽에 상황전파 메시지(소방 자동전파 / 훈련 메시지)를 붙여넣습니다.
3. **[메시지 분석 → 보고서 생성]** 을 누릅니다.
4. 오른쪽 서식을 확인·수정한 뒤 **한글(.hwpx)** 저장 또는 **인쇄/PDF** 합니다.
5. 재난문자 표준문안은 화면 하단에서 복사해 사용합니다.

## 데이터만 고치고 싶을 때 (코드는 안 건드려도 됨)

모든 데이터는 `data/` 폴더의 파일에 들어 있습니다. **이 파일들만 고치면** 됩니다.

| 파일 | 내용 | 언제 고치나 |
|------|------|------------|
| `data/locations.js` | 동해시 관내 장소·주소 | 훈련 배정 장소를 추가/변경할 때 |
| `data/cbs-templates.js` | 재난문자 표준문안(90/157자) | 문안을 추가/수정할 때 |
| `data/gaeyo-templates.js` | 유형별 상황개요 문장 틀 | 상황개요 문구를 다듬을 때 |
| `data/disaster-types.js` | 재난유형 감지 규칙 | 새 재난유형을 추가할 때 |

### 예) 장소 하나 추가하기
`data/locations.js`를 열어 목록에 한 줄 추가:
```js
{dong:"천곡동", place:"동해문화예술회관", addr:"동해시 천곡동 1117 (동해문화예술회관)", mtn:"초록봉", river:"전천"},
```
- `dong`: 행정동/법정동
- `place`: 장소 이름(재난문자·상황개요에 들어감)
- `addr`: 사고장소 칸에 그대로 들어갈 도로명 주소
- `mtn`, `river`: 산불·산사태·호우 상황에서 쓰는 산/하천 이름

쉼표(,)와 따옴표(")를 빠뜨리지 않도록 주의하세요. 저장 후 브라우저를 새로고침하면 반영됩니다.

## GitHub Pages로 웹에 올리기 (관내 공유용)

1. GitHub에 새 저장소(repository)를 만듭니다. (예: `donghae-disaster-report`)
2. 이 폴더의 모든 파일(`index.html`, `data/` 폴더, `README.md`)을 업로드합니다.
3. 저장소 → **Settings → Pages → Source**를 `main` 브랜치 `/ (root)`로 설정합니다.
4. 잠시 후 `https://<아이디>.github.io/donghae-disaster-report/` 주소로 접속됩니다.
5. 이후 데이터 수정은 GitHub 웹에서 `data/` 파일을 직접 편집하면 바로 반영됩니다.

## 참고

- 일시·장소·유형·신고자는 메시지에서 추출하고, 상황개요는 유형별 문장 틀로 자동 작성됩니다. **사용 전 반드시 검토**하세요.
- 신고자 개인정보가 화면에 표시될 수 있으니 공유·녹화 시 유의하세요.
- `.hwpx`가 한글에서 안 열리면 화면의 **호환 문서(.doc)** 링크를 쓰세요.
